Import & Analisis Data Baru

Perbarui data penjualan dari Google Spreadsheet atau File Excel (.xlsx)

ℹ️
Panduan Google Sheets:
Buka Spreadsheet > klik tombol Bagikan (Share) > ubah Akses Umum menjadi "Siapa saja yang memiliki link dapat melihat" (Viewer) > Salin link dan tempel di bawah.
File multi-sheet harian seperti: 16-6-2026, 17-6-2026, dst.
Sheet berisi kolom: PRODUSEN, Nama Produk, Harga.
⚠️
Catatan Keamanan Browser (CORS):
Google membatasi unduhan langsung file multi-sheet dari script web. Anda dapat mengunduh langsung filenya:
⬇️ Unduh XLSX Stok Opname ⬇️ Unduh XLSX Daftar Harga
Setelah terunduh, beralih ke tab Upload File Excel di samping untuk proses instan offline!
⚡
Pemrosesan Cepat & Aman: File diolah 100% langsung di browser pengguna tanpa diunggah ke server lain. Hanya butuh ~2 detik untuk 118 sheet!
